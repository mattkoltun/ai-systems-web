01 · Key concepts

Different layers, different responsibilities

Inference

AI model / LLM

Weights plus inference runtime. Given input context, predicts tokens; may emit natural-language text or structured tool-call requests.

Callable capability

Tool

Function with schema, arguments, permissions and results. Example: search logs, execute code, read a file, query a database.

Interoperability

MCP

Model Context Protocol standardizes exposing tools, resources and prompts between client applications and external servers.

Reusable expertise

Skill

Task-specific instructions, examples, scripts and assets. A skill explains how to perform work; a tool performs an operation.

Control plane

Harness

Software managing prompt composition, memory/context, model calls, tool execution, retries, safety and lifecycle.

Autonomous workflow

Agent

A model coupled to a harness and tools that observes, decides and acts over multiple steps to complete a goal.

Integration packaging

Plugin / connector

Product integration exposing capabilities to an assistant. May use APIs, MCP servers, workflows or specialized logic.

Application

Chat product

UI and backend for conversations, sessions, files, identity, model access and optional agent/tool integrations.

Key boundary: the model does not directly execute actions. It proposes a tool call; the harness decides whether and how to run it and returns observations to the model. MCP is optional—many agents use native function APIs.

04 · Interface contracts
What you actually implement


Model interface
model.generate({
  messages,
  tools,
  instructions
}) → text | tool_calls
Supports structured generation and tool invocation; model output is untrusted until validated.


Tool interface
search_logs({
  service: string,
  since: string
}) → LogEvent[]
Define input schema, capability boundaries, timeout, error format and access controls.


Harness state
{
  conversation,
  checkpoints,
  toolResults,
  budget,
  approvals
}
Use durable state to recover, replay, inspect and constrain multi-step runs.


Minimal agent-loop pseudocode
while remainingBudget > 0:
    response = model.generate(messages, tools=schemas)
    if not response.tool_calls:
        return response.text
    for call in response.tool_calls:
        validate(call); authorize(call)
        result = execute_with_timeout(call)
        messages.append(tool_observation(result))
Production concerns: idempotency, approval gates for destructive actions, injection resistance, tool-output trust, tracing, token budgets, error handling and evaluation.
